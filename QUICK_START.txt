1. Install Required Packages:
   
   Double-click: install.bat
   
   OR manually:
   pip install customtkinter pyttsx3 speechrecognition
   pip install pyaudio psutil pycaw comtypes
   pip install screen-brightness-control pyautogui requests

2. Run MSI:
   
   🎨 UI Version: Double-click run_msi_ui.bat
   📟 Console: Double-click run_msi.bat

╔════════════════════════════════════════════════════════════╗
║                   TROUBLESHOOTING                          ║
╚════════════════════════════════════════════════════════════╝

❌ Mic not working?
   → Check Windows Privacy → Microphone settings
   → Allow Python to access microphone

❌ UI not opening?
   → pip install customtkinter
   → Check Python version (3.8+)

❌ Commands not executing?
   → Run as Administrator
   → Check console log for errors

❌ File not found?
   → Make sure file is in Desktop/Documents/Downloads
   → Try full filename with extension
