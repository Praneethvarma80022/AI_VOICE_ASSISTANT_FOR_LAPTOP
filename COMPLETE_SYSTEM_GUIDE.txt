╔════════════════════════════════════════════════════════════╗
║                    FIRST TIME SETUP                        ║
╚════════════════════════════════════════════════════════════╝

STEP 1: Install Packages
   Run: install.bat
   
   OR manually:
   pip install customtkinter pyttsx3 speechrecognition
   pip install pyaudio psutil pycaw comtypes
   pip install screen-brightness-control pyautogui

STEP 2: Create Account
   1. Run: start_msi.bat
   2. Click "REGISTER" button
   3. Enter username, email, password
   4. Click "REGISTER"
   5. Login automatically appears

STEP 3: Login
   1. Enter your username and password
   2. Click "LOGIN"
   3. MSI UI launches automatically! 🚀

╔════════════════════════════════════════════════════════════╗
║                    TROUBLESHOOTING                         ║
╚════════════════════════════════════════════════════════════╝

❌ Login window won't open?
   → pip install customtkinter sqlite3
   → Check Python version (3.8+)

❌ Can't register?
   → Check username is unique
   → Email must contain @
   → Password minimum 6 characters

❌ MSI UI doesn't launch after login?
   → Check msi_ui.py exists in same folder
   → Check console for error messages
   → Try running msi_ui.py directly

❌ Forgot password?
   → Delete: C:\Users\[Name]\.msi_data\users.db
   → Register again with new credentials
